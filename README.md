# Project_Bookie

# BOOKIE – Book Borrowing and Selling System
# Borrow the Story. Buy the Favorite.

# BOOKIE is a web-based book borrowing and selling system designed to make reading more affordable and convenient. It allows users to borrow books for a certain period or purchase books they want to keep.

# BOOKIE also helps manage book borrowing, returning, and purchasing activities in one platform.

# 🎯 Project Overview

# The Problem
# Buying every book can be expensive, especially for students and people who enjoy reading regularly. Some readers only want to read a book temporarily rather than purchase it.

# Additionally, managing book borrowing, returning, and sales manually can take time and lead to mistakes.

# Our Solution

# -BOOKIE provides a platform where users can:
# -Borrow books instead of purchasing every book.
# -Return borrowed books and track their borrowing status.
# -Purchase books they want to own permanently.

# Our goal is to make books more accessible while providing a convenient way to manage borrowing and selling activities.

# Main Features
# 1. Book Borrowing
# -Browse available books.
# -Borrow books for a specific period.
# -Manage borrowing activities.

# 2. Book Returning and Status Updates
# -Return borrowed books.
# -Update borrowing and returning statuses.
# -Track the current status of borrowed books.

# 3. Book Buying
# -Browse books available for purchase.
# -Select and purchase books.
# -Buy books to keep permanently.

# Technologies Used
# frontend -react js
# backend - node js + express js
# database - MongoDB

# Deployment
# BOOKIE is planned to be deployed using Vercel.
